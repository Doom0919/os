Process Control Block

Process Control Block (PCB) нь үйлдлийн системийн процессийн тухай мэдээллийг хадгалдаг өгөгдлийн бүтэц юм.

Process ID
Процессийг ялгах өвөрмөц дугаар
Process State
Процессын одоогийн төлөв (Ready, Running, Waiting)
Program Counter
Дараагийн гүйцэтгэх зааврын хаяг
CPU Registers
CPU-ийн регистрүүдийн утгууд
Memory Management Info
Санах ойн хуваарилалт, сегмент/хуудасны мэдээлэл
I/O Status Info
Оролт/гаралтын төхөөрөмжийн төлөв ба хүсэлтүүд
💡 'D' → дараагийн слайд | 'A' → өмнөх слайд руу буцах
